### syntax
Every reply has two parts, in this order. First, your thinking, in plain prose: what
you believe the bomb is, what you just learned, and why you are sending what follows.
It reaches nobody and changes nothing, but it is not optional — a reply that is only a
code block is incomplete. Then your calls, all of them in one fenced code block, last.
Only what is inside the block is sent.

Nothing is executed: calls return nothing, and variables, conditionals and loops are
ignored. Write only literal top-level calls.
