# Hints

- The routes, by name. Speech reaches Mute and Blind, and never Deaf. Gestures
  reach Deaf and Mute, and never Blind. Deaf can speak and gesture, Mute can
  only gesture, Blind can only speak. Check every message against this list
  before you send it.

- Deaf invents the gesture code out loud before anything else moves, and
  everyone else's opening move is waiting for it. The manual's verdict reaches
  Blind only as Deaf's spoken order.

- Whatever the code becomes, it starts by being able to say YES, NO, HOLD and
  DONE. Grow it only when a message will not fit.
