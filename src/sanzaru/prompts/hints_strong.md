# Hints

- Pick the channel by the receiver, not by habit. A message sent in a sense they
  lack is not a message; it is a turn spent talking to the room.

- Exactly one of you can read the signs and still speak. Their spoken lines are
  the answer's only road to the hands, so spend them well.

- Agree on a small code before trading facts. A code invented mid-stream settles
  nothing, and one set first makes every later message cheap.
